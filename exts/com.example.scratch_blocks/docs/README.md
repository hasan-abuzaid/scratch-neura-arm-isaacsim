# Scratch Blocks Demo

A coordinate-based Isaac Sim 6.0.1 Scratch-style editor prototype:

- drag `Print` and `Wait` templates onto a free canvas;
- snap puzzle-shaped blocks through parent/next connectors;
- move or disconnect complete block stacks;
- edit block parameters;
- run or stop the program;
- save/load the program as JSON.

See the top-level `README.md` for installation and testing instructions.
